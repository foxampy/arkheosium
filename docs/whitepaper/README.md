## Формат для ИИ

Текстовая документация продублирована в двух машиночитаемых форматах — оба генерируются из markdown-файлов скриптом [`build-kb.py`](./build-kb.py).

### `arkheosium-kb.json` — структурированная база знаний
Единый объект для загрузки целиком и навигации:
```
{
  "name", "version", "description",
  "canonical_facts": { entities, economics, internal_token, verification, knowledge, domains },
  "documents": [ { id, order, kind, topic, file, title, intro, word_count, section_count,
                   sections: [ { heading, level, content, word_count } ] } ]
}
```
Используйте, когда нужен весь контекст сразу, точные факты (`canonical_facts`) или обход по документам/секциям.

### `arkheosium-kb.jsonl` — чанки по секциям (для RAG)
По одной записи на секцию (59 записей) — идеально для эмбеддингов и поиска:
```
{ "id": "<doc-id>::<slug>", "doc_id", "doc_title", "heading", "level",
  "order", "section_index", "text", "word_count" }
```
Каждый чанк самодостаточен (заголовок + текст секции). `id` стабилен между сборками — удобно для инкрементальной индексации.

### `arkheosium-graph.json` — граф связей
Узлы и рёбра всей экосистемы (43 узла / 66 связей): сущности (ArkheOSium, FoxampyForge, UnicapInvest), документы, экономика, векторы, 7 модулей, 7 библиотек (онтология), продукты данных MRV и DAO — со всеми связями между ними.
```
{ "nodes": [ { id, label, type, group, color, meta } ],
  "edges": [ { source, target, label, type } ] }
```
Тот же граф встроен в `arkheosium-kb.json` (поле `graph`) и визуализирован в `whitepaper.html`.

### `whitepaper.html` — презентационная версия
Единый оформленный документ (dark glassmorphism) со всеми текстами, каноническими фактами и интерактивным графом. Самодостаточный, без внешних зависимостей — открывается двойным кликом в любом браузере.

### Пересборка
```bash
python build-kb.py      # markdown -> JSON + JSONL + graph
python build-html.py    # -> whitepaper.html
```
Первый скрипт читает 5 markdown-файлов, режет по заголовкам `#`/`##`, строит граф и перезаписывает БЗ. Второй рендерит презентационный HTML. Markdown-файлы остаются мастер-версией.
