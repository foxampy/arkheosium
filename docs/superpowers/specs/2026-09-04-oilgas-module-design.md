# Модуль «Газнефть» — дизайн

Дата: 2026-09-04
Статус: согласован владельцем, принят в работу

## Задача

Добавить в ArkheOSium домен нефти и газа и общий домен экологии, показать их на
глобусе и карте наравне с водой, дать странице модуля онбординг и whitepaper,
собрать каталог R&D, оборудования, услуг, продуктов и проектов, включая линейку
LabForge и интеграционный модуль для партнёрских компаний. Отдельным пунктом —
исправить кластеризацию меток на карте.

Географический фокус: Центральная Азия, с наибольшей детализацией по Узбекистану.

## Границы

Партнёрская сервисно-добывающая компания на витрине не называется. «Первый
партнёр» как факт сделки не публикуется. Публикуется регион присутствия —
Центральная Азия.

Числовые характеристики разработок LabForge (частотные диапазоны, точность,
разрешение) и прайс на них в этой итерации не публикуются: публичного основания
нет. Публикуется описание метода, стадия готовности и опора на действующие
стандарты. Позиция без цены допустима, позиция с выдуманной ценой — нет.

## Правило данных

Действует правило корпуса: утверждение без основания не вносится. В кодовой базе
оно уже выражено типом — `RDItem._source: { file, quote }` в `src/data/rd-data.ts`.
Каждая новая запись каталога и каждый объект карты несут источник. Для позиций,
собранных из публичных отраслевых источников, `_source` содержит URL.

Разделение слоёв соблюдается: исследовательские заметки, сравнения и пробелы в
источниках в UI не рендерятся. На витрину идёт результат, а не процесс поиска.

## Архитектура

### Реестр модулей

Сейчас домен прописывается в четырёх местах: маршрут в `src/App.tsx`, пункт в
`NAV_GROUPS` в `src/components/layout/Header.tsx`, команда в
`src/components/CommandPalette.tsx`, ключ в `src/lib/domains.ts`. Три новых
домена по этой схеме — двенадцать рассинхронизируемых правок.

Вводится `src/lib/modules/registry.ts`: модуль описывается одним объектом
(ключ домена, маршрут, ленивый компонент страницы, группа навигации, иконка,
команда палитры). Маршруты, навигация и палитра читают реестр.

### Домены

`src/lib/domains.ts` расширяется двумя ключами:

- `oilgas` — Нефть и газ, 🛢️
- `ecology` — Экология, 🌍

Существующие шесть (`water`, `energy`, `minerals`, `nature`, `agriculture`,
`climate`) сохраняются. `minerals` остаётся под твёрдые ископаемые.

### Кластеризация карты

Текущее поведение — `clusterMarkers()` в `src/components/map/Map.tsx:82`
группирует метки по экранному радиусу 48 px и рисует кружок с числом.
География в группировке не участвует.

Новое поведение — иерархическая географическая агрегация по зуму:

| Зум | Уровень агрегации |
|---|---|
| < 4 | страна |
| 4 – 6.5 | область / вилоят |
| 6.5 – 9 | район, месторождение, узел |
| > 9 | отдельные объекты |

Вместо кружка с количеством — чип с названием региона и разбивкой по доменам.
Клик разворачивает уровень вниз.

Основание для группировки уже есть: объекты несут `region` (название области,
например `'Джиззакская область'`) и `country` — см. `src/data/objects/uz-objects.ts`.
Добавляется реестр центроидов и границ областей Центральной Азии.

### Глобус

Переключатель ресурсов поверх существующей палитры `DOMAIN_CONFIG`. Выбор домена
фильтрует объекты и подтягивает связанные субъекты, R&D и геослои.

## Состав контента

### Объекты

Публично документированные месторождения, ГПЗ, НПЗ и газохимические комплексы
Центральной Азии в формате `FullObjectData` (`src/types/object-full.ts`).
Плотность по Узбекистану выше, чем по соседним странам.

### Каталог

Пять групп, наполняются реальными, публично документированными технологиями:

- Мониторинг состояния оборудования и предиктивное обслуживание
- Мониторинг метана и выбросов
- Очистка попутных вод и рекультивация
- Цифровые двойники, ИИ, токенизированный MRV
- Газопереработка, GTL, газохимия

### LabForge

Собственные разработки оформляются по образцу водяной линейки
(`RD-AQUACELL-GO` в `src/data/rd-data.ts`): описание метода, стадия, опора на
действующие стандарты. Вибродиагностика соотносится с ISO 20816 и ISO 13373,
волоконно-оптическая акустика — с DAS как отраслевым классом, запечатывание
данных в хэш-ноды — с классом DePIN/MRV. Заявленное называется заявленным,
стадия указывается честно.

### Интеграционный модуль

Услуга для сервисно-добывающих компаний: CRM, DAO-контур, ИИ, автоматизация.
Описывается состав пакета, результат для клиента, формат работы и порядок
заказа. Компания-заказчик не называется.

## Порядок работ и деплой

Итерациями, с выкладкой после каждой:

1. Реестр модулей, домены, иерархическая кластеризация карты
2. Геоданные регионов, объекты нефтегаза Центральной Азии, переключение на глобусе
3. Страница модуля: онбординг и whitepaper
4. Каталог, линейка LabForge, интеграционный модуль

## Проверка перед выкладкой

По каждому тексту, уходящему в production:

1. Текст предназначен клиенту?
2. Создаёт коммерческую ценность для посетителя?
3. Это результат, а не процесс мышления?
4. Это не описание пробела в данных и не черновой reasoning?

Хоть один ответ «нет» — в production не идёт.
