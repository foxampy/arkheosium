## 1. Концепция и игровая механика

### 1.1 Суть программы
AquaCell превращает рутинное измерение качества воды в **геймифицированную гражданскую науку**:
пользователь покупает устройство, выходит на прогулку, находит водоём на карте, делает анализ — и получает выплату в VOD токенах. Чем уникальнее точка, тем дороже данные.

### 1.2 Игровой цикл (User Journey)

```
[Покупка устройства]
        ↓
[Регистрация + привязка к аккаунту VODPROM]
   → Серийный номер устройства → NFT-верификация картриджа → SBT «Гражданский гидролог»
        ↓
[Открыть карту перед прогулкой]
   → Карта показывает: водоёмы, реки, фонтаны, скважины в радиусе
   → Цветовая маркировка: 🟢 нет данных (высокая оплата) / 🟡 данные устарели / 🔴 уже проверяется
   → Система назначает «Миссии»: приоритетные точки с бонусом ×1.5–×3
   → Нельзя брать точку, которую уже занял другой пользователь (бронь 2 ч)
        ↓
[На месте: погружение картриджа]
   → Пользователь следует инструкции в приложении (≥ 90 сек для стандарт, ≥ 3 мин для Pro)
   → GPS автоматически фиксируется
   → Устройство вибрирует: «Анализ завершён»
        ↓
[Автоматическая загрузка данных]
   → BLE → мобильное приложение → хэш-пакет → VOD Chain
   → Пользователь видит результаты в реальном времени
        ↓
[Начисление вознаграждения]
   → VOD токены на кошелёк
   → Рейтинговые очки и уровень
   → Разблокировка бейджей и новых зон
```

## 3. Система предотвращения фальсификации

### 3.1 Уникальные картриджи (Razor & Blades модель)

Каждый картридж имеет:
- **Физическую защиту**: NFC-чип Mifare Ultralight с одноразовой записью (WORM) — при активации записывается device_id + timestamp + lot_number; повторная запись невозможна
- **QR-код с криптохэшем**: scannable визуальная верификация
- **NFT-верификация**: при покупке картриджа пользователь сканирует NFC → смарт-контракт на VOD Chain создаёт NFT картриджа, привязанного к device_id
- **Счётчик использований**: SE-чип устройства отслеживает N оставшихся тестов; картридж с превышенным лимитом = невалидный
- **Batch-лоты**: каждый лот картриджей имеет криптографическую подпись производителя; устройство отказывается работать с неподписанными лотами (защита от контрафакта)

### 3.2 Аппаратный защищённый элемент (SE Chip)

Устройство содержит SE-чип (аналог Apple Secure Enclave / ARM TrustZone):
- Генерирует пару ключей при первой активации (приватный ключ **никогда не покидает SE**)
- Каждый пакет данных подписывается: `sign(device_privkey, hash(measurements + GPS + timestamp + cartridge_id))`
- Подпись верифицируется VOD Chain до записи данных
- SE хранит: device_id, счётчик тестов, последние 50 хэшей (защита от replay-атак)

### 3.3 Защита от манипуляций с данными

| Вектор атаки | Защита |
|-------------|---------|
| Подделка показаний (ввод вручную) | Данные только из SE-подписанного пакета; ручной ввод невозможен |
| Повтор старого пакета (replay) | SE-счётчик + timestamp: узел отклоняет пакет с дублированным nonce |
| Подмена GPS | GPS-координаты включены в SE-подписанный пакет; подмена на телефоне ломает подпись |
| Использование чужого картриджа | NFT картриджа привязан к device_id; несовпадение = отклонение |
| Несколько измерений одного места | Система бронирования: в радиусе 50 м разрешён только 1 активный тест |
| Подделка картриджа | NFC WORM + batch-подпись производителя |
| Сговор нескольких пользователей | Cross-validation: 3+ измерения в одной точке за 30 дней усредняются; выброс > 2σ → флаг «требует проверки» |

### 3.4 Верификация и ценность данных

**Уровни верификации данных:**
1. **Raw** — загружено, подпись валидна
2. **Geo-verified** — GPS совпадает с заявленным объектом ±200 м
3. **Cross-validated** — минимум 3 пробы с разных устройств в точке → статус «Verified»
4. **Expert-reviewed** — лабораторное подтверждение → «Gold Standard»

**Цена данных зависит от:**
- Уровня верификации (×1 / ×1.3 / ×2 / ×3)
- Редкости точки (последнее измерение >30 дней → ×1.5)
- Опасного уровня загрязнения (обнаружен ПДК+ → ×3 + алерт)
- Спроса (аналитики, регуляторы, страховые платят за подписки)

## 4. Токеномика вознаграждений

### 4.1 Как начисляются VOD токены

```
reward = base_price(location) × quality_multiplier × rarity_multiplier × device_tier
```

- **base_price**: $2 (плотные города) → $15 (малопосещённые зоны)
- **quality_multiplier**: AquaCell Go ×1.0 / Pro ×1.5 / Lab ×2.5
- **rarity_multiplier**: если данных нет >30 дней → ×1.5; нет >90 дней → ×2.0
- **bonus**: первый в точке за день → +20%; обнаружено критическое загрязнение → +×3

### 4.2 Рейтинг и уровни (Gamification)

| Уровень | Проб | Бонус | Разблокировка |
|---------|------|-------|---------------|
| 🔵 Наблюдатель | 0–49 | — | Базовые зоны |
| 🟢 Гидролог | 50–199 | +10% | Эксклюзивные миссии |
| 🟡 Эксперт | 200–499 | +25% | Лабораторные задания |
| 🟠 Страж воды | 500–999 | +40% | DAO-голосование, приоритет |
| 🔴 Хранитель | 1000+ | +60% | Модерация, ревью новых точек |

### 4.3 Специальные миссии
- **Экспедиция**: проверить 5+ объектов за 1 день → ×2.0 бонус
- **Первопроходец**: первый в регионе → NFT «Первопроходец [Река/Озеро]»
- **Антикризис**: выявить загрязнение → бонус $50+ + токен «Детектив»
- **Научный**: совместить данные с официальными лабораторными → ×3

## 5. Система датчиков для инфраструктурных объектов (AquaNode)

### 5.1 Концепция

Стационарные датчики для насосных станций, водозаборов, каналов — более богатые данные, чем у карманных устройств, но та же система защиты от фальсификации. Датчик **сам берёт пробы** по расписанию, без участия человека.

### 5.2 Технические характеристики AquaNode Pro (объектный)

- **Параметры**: pH, T, TDS, DO, ORP, мутность, расход Q, давление P, уровень H
- **Периодичность**: базовый режим 15 мин; тревожный режим 1 мин
- **Автопробоотбор**: мини-перистальтический насос, объём 5 мл, промывка септ. раствором между пробами
- **Связь**: NB-IoT (первичный) + LoRaWAN (резервный) + GPRS (третичный)
- **Питание**: 12V от объекта + LiPo 10 Ач (резерв 72 ч)
- **SE-чип**: тот же механизм подписи, что и у карманных моделей
- **Корпус**: IP68, нержавеющая сталь 316L, защита от вандализма

### 5.3 Защита целостности объектного датчика

| Тип угрозы | Механизм защиты |
|-----------|----------------|
| Физический демонтаж | Акселерометр 3-axis: движение → немедленный алерт в DAO + запись в блокчейн |
| Вскрытие корпуса | Герметичный датчик вскрытия (tamper wire) → алерт + SE блокировка данных |
| Обход датчика (байпас) | Расходомер + баланс воды: если Q отличается от ожидаемого → флаг |
| Подмена реагентов (картриджей) | NFC-WORM на каждом реагентном блоке; замена без авторизации = стоп |
| Атака на канал связи | End-to-end: данные шифруются SE до выхода из датчика; транспорт не имеет значения |
| Манипуляция ПО | Secure Boot: только прошивка с подписью VODPROM запускается |
| Обесточивание для сокрытия данных | Алерт на «нет данных >30 мин» = равнозначен алерту загрязнения; DAO уведомлен |

### 5.4 Прямая связь с DAO

Объектный датчик связан напрямую с DAO-смарт-контрактом:
1. **Автоматические выплаты оператору**: поступают только при наличии валидных данных за период
2. **Экстренный DAO-алерт**: при обнаружении ПДК+ или тревоги датчика → DAO получает уведомление без посредников
3. **Голосование по аномалии**: DAO может инициировать внеплановую инспекцию объекта
4. **ESG-токены**: оператор объекта получает ESG-рейтинг на основе непрерывных данных → влияет на условия кредитования

### 5.5 Финансовая модель объектного датчика

| Статья | Значение |
|--------|----------|
| Стоимость датчика | $2 000–5 000 |
| Абонплата DAO | $100–500/мес |
| Выплата оператору | $200–800/мес (зависит от востребованности данных) |
| ROI оператора | 6–18 месяцев |
| Выплата DAO за данные | Через подписки аналитиков, регуляторов, страховых |

## 7. Техническая архитектура данных

```
[Устройство/Датчик]
    → SE-подписанный пакет (protobuf)
    → BLE/NB-IoT/LoRa
[Mobile App / Gateway]
    → Валидация подписи
    → Обогащение метаданными (battery, app version, network)
    → HTTPS POST → VODPROM API
[VODPROM Backend (Supabase)]
    → Запись в PostgreSQL: water_measurements
    → Обновление объекта: last_measurement, quality_index
    → Kafka/Realtime → стриминг подписчикам
[VOD Chain (Blockchain layer)]
    → Hash пакета → Transaction
    → NFT картриджа update (использован N тестов)
    → Начисление вознаграждения (смарт-контракт)
[VODPROM Map / Dashboard]
    → Цветовая тепловая карта качества воды
    → Timeline объекта
    → Алерты (ПДК+, тревога датчика)
```
