## 2. Ключи Gemini (кладёт владелец в Vercel)

Для параллельной работы агентов и обхода rate-limit — **4 ключа**. В Vercel → Project `arkheosium` → Settings → Environment Variables (все среды: Production/Preview/Development):

| Имя переменной | Значение |
|----------------|----------|
| `GEMINI_API_KEY_1` | ключ №1 |
| `GEMINI_API_KEY_2` | ключ №2 |
| `GEMINI_API_KEY_3` | ключ №3 |
| `GEMINI_API_KEY_4` | ключ №4 |
| `GEMINI_KEY_COUNT` | `4` |

Серверная функция `/api/genesis` читает `GEMINI_API_KEY_1..N`, распределяет параллельные вызовы агентов по ключам (round-robin) — ускорение и устойчивость к лимитам. **Ключи никогда не попадают в клиентский бандл.**

Модели: `gemini-2.5-flash` (быстрые агенты: research, tech-select), `gemini-2.5-pro` (тяжёлые: ТЭО, архитектура).

## 3. Genesis Engine — дизайн модуля

**Суть:** автономный агентный конвейер, превращающий сырой вход (объект / ресурс / инициатива / концепция) в структурированный ПРОЕКТ с research, ТЭО и подбором оптимальных технологий/оборудования/методологий/инноваций. Плюс модуль веб-визуализации и компоновки (аналог Manus / Replit). Прообраз в whitepaper — «Development Engine / Genesis Engine», Chapter 32.

### Доступ (гейтинг по подписке/админам)
- Страница `/genesis` **открыта всем** — можно запустить генерацию и видеть работу агентов (демо/превью).
- **Полускрытый режим** через существующие `AuthGate` + `PremiumOverlay`. По подписке и администраторам открыты:
  - **Детальный просмотр** результата (полное ТЭО, подбор технологий, артефакты).
  - **Скачивание** артефактов/проекта (экспорт).
  - **Публикация** в Project Hub.
  Без подписки — только усечённое превью (заблюрено/обрезано `PremiumOverlay`).
- Аккаунты/подписка уже есть: `useAuth`, `AuthPage`, `ProfilePage`, `AdminInvitePage`, `PremiumOverlay`, `AuthGate`.

### Архитектура
- **Фронт:** `src/pages/GenesisPage.tsx` + компоненты (ввод, лента прогресса агентов, результат-проект, Studio-превью).
- **Бэк:** `/api/genesis` (Vercel Serverless Function) — держит ключи, оркестрирует агентов, стримит статус. Ключи только тут.
- **БД (Supabase):** новые таблицы — все запросы/ответы/наработки сохраняются системно:
  - `genesis_runs` — сессия генерации (вход, автор, статус, стоимость токенов).
  - `genesis_steps` — по-агентно: prompt, ответ, артефакт, тайминги.
  - `genesis_artifacts` — итоговые файлы/визуализации/код.
  - `genesis_projects` — опубликованные проекты (связь с Project Hub).

### Агентный конвейер (полностью автономный)
1. **Research** — анализ входа, аналоги, контекст (`flash`).
2. **Concept** — концепция + варианты (`flash`).
3. **Tech selection** — подбор технологий/оборудования из каталога `tech-marketplace` + сравнение (`flash` + function-calling к нашим данным).
4. **ТЭО** — экономика: капзатраты, окупаемость, риски (`pro`).
5. **Studio / Visualization** — генерация интерактивной веб-визуализации и компоновки проекта (полноценный веб-модуль: код + live-превью в песочнице iframe, как Manus/Replit).
6. **Assembly** — сборка структурированного проекта, сохранение в БД.

Прогресс стримится на UI (видно работу агентов). Полностью автономно, без обязательного ручного подтверждения (по решению владельца).

### Публикация / скачивание / детали (по подписке + админ)
- Кнопка **«Опубликовать в Project Hub»** → проект из `genesis_projects` попадает в `/hub`, становится полноценной карточкой. Гейтинг: подписка/админ.
- Кнопка **«Скачать»** (экспорт артефактов/проекта). Гейтинг: подписка/админ.
- **Детальный просмотр** (полное ТЭО + артефакты). Гейтинг: подписка/админ.
- Функция публикации: валидация → запись в hub-таблицу → редирект на карточку.
