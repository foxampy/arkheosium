## Зачем этот архив, если есть git

Git хранит строки. Он отвечает на вопрос «что изменилось» и не отвечает
на вопрос «почему так решили». Через полгода дифф `TokenomicsPage.tsx`
покажет, что 887 строк заменены на 200, и не покажет, что решение
принималось не про вёрстку, а про то, можно ли публиковать число, у
которого нет документа-основания.

Поэтому версия архивируется дважды: тегом — состояние кода, этим
каталогом — состояние подходов. Восстановить первое из второго нельзя,
но понять второе без первого — тоже.

## Что представляла собой v0.1

Платформа ArkheOSium: React 18 + Vite + TypeScript 5.6, интерфейс целиком
на русском. Тематически — водные и ресурсные объекты Центральной Азии:
карта и глобус, каталоги объектов и субъектов, разборы проектов,
отраслевой модуль «Газнефть», витрина контура, партнёрские входы.

v0.1 — это не первая работающая версия и не релиз. Это **срез, на котором
из платформы вынуты утверждения без основания**. До него продукт публиковал
курс невыпущенного токена, ставки доходности, размер казны DAO, число
держателей и TVL. Содержание коммита `77041f4` — снятие этого, причём
снятие с сохранением следа: ни одна страница не удалена и ни один маршрут
не заменён редиректом.

## Чего в v0.1 нет

Ноль пишется нулём, поэтому перечисляется явно:

- Выпущенных токенов — **ноль**. Любых: ресурсных, расчётных, иных.
- Объектов с аудированным денежным потоком — **ноль**.
- Реальных замеров с поверенных приборов в системе — **ноль**.
- Учреждённых органов управления (DAO) — **ноль**.
- Проведённых голосований и принятых решений — **ноль**.
- Форм приёма средств — **ноль**; юридической формы привлечения нет.
- Проверок документов и референций поставщиков — **ноль**.
- Документов, прикреплённых к объектам, — **ноль**.

Каталог `src/data/whitepaper/` (главы вайтпейпера как данные) в состав
v0.1 **не входит**: на момент тега его не существовало. Он относится к
следующему шагу — см. `../../EVOLUTION.md`.
