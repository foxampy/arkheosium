## ⚠️ Методологическая заметка о верификации

Прямой HTTP-доступ к сайтам (WebFetch / http_fetch) в этой сессии был **заблокирован политикой окружения**.
Верификация проводилась через инструмент веб-поиска, который возвращает реальные URL и извлечённое
содержимое страниц. Это означает:

- **Все URL ниже — реальные адреса, возвращённые поисковой выдачей**, ни один не сконструирован вручную.
- Суммы, даты и условия взяты из содержимого, извлечённого поиском из этих источников.
- **Перед публикацией в продакшн-модуле каждую запись следует перепроверить прямым открытием URL** —
  особенно поля `deadline` и `status`, которые быстро устаревают.
- Там, где источники противоречат друг другу или данных не было, поле оставлено `null` и это явно помечено.

Легенда статусов (на 2026-07-28):
`open` — приём заявок идёт · `upcoming` — объявлено, приём ещё не начался ·
`rolling` — приём круглогодично · `annual-recurring` — ежегодный цикл ·
`closed-recent` — дедлайн недавно прошёл, следующий цикл ожидается.

#### 1. GEF Small Grants Programme (SGP)

| Поле | Значение |
|---|---|
| `id` | `gef-sgp` |
| `organizer` | Global Environment Facility, реализуется UNDP |
| `kind` | grant |
| `category` | ecology, water |
| `status` | rolling (через национальные офисы; циклы объявляются по странам) |
| `opens` / `deadline` | null / null — определяется национальной программой |

Для ARKHEOSIUM это самый доступный вход в систему ГЭФ: небольшой бюджет, но реальный шанс для локальных пилотов в Приаралье через НКО-партнёра. Заявки подаются в национальный офис SGP, а не в глобальный секретариат.
