# ЧАСТЬ 1. МЕТОДИКА РАСЧЁТА — ЕДИНИЧНЫЕ СТАВКИ

Расчёт бюджета любого грантового проекта строится по формуле:

```
БЮДЖЕТ ПРОЕКТА = Σ (объём работ по статье × единичная ставка) + резерв на непредвиденное (10%)
```

## 1.1. Единичные ставки (модельные, региональные)

| Статья | Единица | Ставка *(модельная)* | Комментарий |
|---|---|---|---|
| Стипендия и содержание соискателя диссертации | ставка/год | 18 000–24 000 $ | включает стипендию, командировочные, публикации |
| Полевой сезон на один полигон | сезон | 8 000–15 000 $ | логистика, транспорт, расходники, суточные |
| Телеметрический узел (датчик + контроллер + монтаж) | узел | 3 000–6 000 $ | зависит от типа параметра (уровень/качество/метео) |
| Лабораторный анализ пробы воды или почвы | проба | 40–120 $ | зависит от панели показателей |
| Ветеринарный отбор и анализ пробы у животного | особь | 150–400 $ | зависит от вида и панели тестов |
| Обучение специалиста / капасити-билдинг | участник курса | 500–1 200 $ | очный формат, включая материалы |
| IT-инфраструктура и интеграция данных | % от бюджета проекта | 10–15% | хранение, онтология, интеграционная шина |
| Резерв на непредвиденные расходы | % от бюджета проекта | 10% | стандартная норма донорских бюджетов |

**Как пользоваться таблицей.** Диапазоны отражают неопределённость на стадии концепции; при подготовке полной заявки каждая ставка сужается до точечного значения после получения предложений поставщиков и рекогносцировки на месте. До этого момента в заявке указывается середина диапазона с явной пометкой «модельная оценка».

## 1.2. Формула для полигона за один сезон

```
Стоимость полигон-сезона = логистика сезона (8–15 тыс $)
    + число узлов телеметрии × 3–6 тыс $
    + число проб воды/почвы × 40–120 $
    + число проб фауны × 150–400 $
```

Для трёх типовых полигонов (деградированный / контрольный / восстанавливаемый), 4 сезона в год, при среднем объёме 8 узлов и 40 проб на полигон за сезон, модельная оценка одного полного годового цикла наблюдений по трём полигонам — диапазон **180 000–340 000 $/год**, без учёта стипендий и IT-контура.
