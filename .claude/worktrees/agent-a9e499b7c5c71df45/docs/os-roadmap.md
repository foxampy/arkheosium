# ARKHEOSIUM — Roadmap развития до полноценной ОС

Дата: 2026-07-15
Статус деплоя: прод https://arkheosium.vercel.app

## 0. Что уже исправлено в этой итерации
- Краш главной (глобус): `_h is not a constructor` — заменил спрайты + `CanvasTexture` на проверенные `mesh` + `Html`.
- ErrorBoundary теперь сбрасывается при смене маршрута (`resetKey={location}`) — падение одной страницы больше не «ломает» всё приложение (это и вызывало ложные 404).
- Удалён маркетплейс водных ресурсов (торговля водой/правами): убран из дока, бургер-меню, дашборда и роутов. В доке заменён на «Тех.маркет».

---

## 1. Текущее состояние (аудит)
- **~40 страниц**, 8 групп в бургер-меню, док из 12 модулей на глобусе.
- Данные: Supabase (`water_resources`, `projects`, `partnerships`, алерты).
- Стек: React 18 + R3F v8/drei v9, wouter, TanStack Query, framer-motion, i18next, PWA.
- **Проблемы:** нет единой ролевой модели/доступов; много «mock»-страниц без реальных данных; навигация плоская (список ссылок), нет глобального поиска и командной палитры; дублирующиеся сущности объект/субъект/проект без сквозного графа связей.

---

## 2. Навигация и бургер-меню (обновление)
Цель: превратить меню-список в настоящую «оболочку ОС».

- **Командная палитра (⌘K / Ctrl+K)** — глобальный поиск по объектам/субъектам/проектам/страницам + быстрые действия. Приоритет: высокий.
- **Роле-зависимое меню** — пункты фильтруются по роли (гость / инвестор / партнёр / оператор / админ).
- **Избранное и «недавнее»** — закрепление модулей, история переходов.
- **Реорганизация групп** (сейчас 8) → 5 логичных доменов:
  1. Обзор (Глобус, Карта, Дашборд, Аналитика)
  2. Инфраструктура (Проекты, Объекты, Субъекты, IoT, Алерты, Цифровой двойник)
  3. Знания (Каталог, R&D, Тех-маркетплейс, Документы, Whitepaper, ARAL NEXUS)
  4. Инвестиции и право (Инвестиции, Блокчейн, Регуляторика, Токенсейл)
  5. Сообщество и аккаунт (Сообщество, Сообщения, Контакты, Рабочий стол, Профиль, Настройки)
- **Нижний таб-бар на мобильном** (5 иконок: Глобус, Карта, Проекты, Поиск, Профиль) — сейчас всё спрятано в бургер.
- **Хлебные крошки + контекстные действия** на детальных страницах.

---

## 3. Новые модули / страницы
Приоритет P0 (ядро) → P2 (позже):

- **P0 · Глобальный поиск / Command Palette** — единая точка входа.
- **P0 · Цифровой двойник объекта** (`/hub/object/:id/twin` уже есть маршрут — довести до реального 3D + телеметрия IoT).
- **P0 · Ролевая модель и права доступа** (гость/инвестор/партнёр/оператор/админ) + защищённые маршруты.
- **P1 · Центр уведомлений** — единая лента алертов/сообщений/системных событий (сейчас алерты и сообщения раздельны).
- **P1 · Конкурсы / Хакатоны / Гранты** — отдельные страницы (сейчас упоминаются, но нет).
- **P1 · Календарь событий** (форумы, дедлайны грантов, майлстоуны проектов).
- **P1 · Граф связей** объект↔субъект↔проект↔R&D (визуальный граф, а не только списки).
- **P2 · Обучение / Академия** (онбординг-курсы по платформе и водной тематике).
- **P2 · API / Разработчикам** (публичный доступ к данным, ключи, вебхуки).
- **P2 · Маркетплейс технологий v2** — довести `/tech-marketplace` до реальных карточек с оборудованием/поставщиками (это легитимный рынок, в отличие от воды).

## 4. Функции (сквозные)
- **Реальные данные вместо mock** — UpdatesPage, Marketplace(tech), Community, Dashboard подключить к Supabase.
- **Авторизация** — довести AuthPage/Activate/AdminInvite до рабочего флоу (magic link / OAuth), профиль с ролью.
- **Оффлайн-режим PWA** — кэш ключевых данных, очередь действий.
- **Пуш-уведомления** — уже есть каркас (`useAlertNotifications`), довести до реальных подписок по объектам/регионам.
- **i18n** — добить переводы (RU/EN/UZ), сейчас часть строк захардкожена.
- **Производительность** — код-сплит тяжёлых чанков (EarthGlobePage ~900kB, maps ~800kB), lazy-загрузка three только на глобусе/карте.
- **Онбординг новых пользователей** — интерактивный тур по ОС.

## 5. Глобус (доведение)
- Кластеры: при клике «разлетаются» плавнее (сейчас долли-камера — ок), добавить анимацию раскрытия.
- Тип-фильтры на глобусе (объекты/субъекты/проекты toggle).
- Тепловая карта плотности при сильном отдалении.
- Линии-связи между связанными сущностями (дуги по поверхности).
- Легенда (цвет = тип) в углу экрана.

## 6. Предлагаемые фазы
- **Фаза 1 (ядро UX):** командная палитра, реорганизация меню, мобильный таб-бар, ролевая модель, реальные данные в Updates/Dashboard. 
- **Фаза 2 (данные и связи):** граф связей, центр уведомлений, цифровой двойник, календарь, конкурсы/хакатоны/гранты.
- **Фаза 3 (масштаб):** API для разработчиков, академия, оффлайн-PWA, тех-маркетплейс v2, i18n-полнота, оптимизация чанков.

Каждая фаза → отдельный спек через `/brainstorming` → план через `/writing-plans`.
